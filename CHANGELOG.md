# Changelog

## 1.0.0 - 2026-09-19

Initial release.

- `effective.py`: loads managed policy (`managed-settings.json` plus
  `managed-settings.d/*.json`), `--settings`, `.claude/settings.local.json`,
  `.claude/settings.json`, `~/.claude/settings.json` and the global-config keys of
  `~/.claude.json`; merges them the way the docs describe (scalars override, lists
  union, objects per leaf, `fallbackModel` / `modelPicker` taken whole, the
  security keys where a stricter lower value wins); prints every effective key with
  the file that decided it, permission rules and hooks itemized per source.
- Findings: key set in a file whose scope cannot set it (IGNORED), value shadowed by
  a higher layer, `allow` rule outranked by `ask` / `deny`, typo'd key with
  did-you-mean, file skipped for invalid JSON, project rules and env waiting on
  folder trust, `disableAllHooks`, bypass mode disabled by policy, `env` var also in
  the shell, restart-only keys.
- `--explain KEY` from the embedded settings index (231 keys, scope / topic /
  description) generated by `docs/update_index.py` from the docs page, with a saved
  snapshot so CI can check the generator still parses it.
- `--key`, `--problems-only`, `--full`, `--strict`, `--json`, `--settings`,
  `--project`.
- 38-test suite on throwaway layers and a CI matrix (Windows / macOS / Linux, Python
  3.10 / 3.13).
